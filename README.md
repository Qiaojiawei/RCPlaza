# RC Plaza — RC 遥控车物理模拟游戏

按 `RC模拟游戏设计.md` 实现的 Unity 2022.3 完整工程：两辆真实参数还原的遥控车
（短卡 SCT 型 / 大脚 MT 型）、自研 Pacejka 轮胎物理、raycast 悬挂、三段式无刷电机
扭矩曲线、锂电电压骤降与低压保护、三层程序化音频、住宅小区广场砖地场景，
性能锚点 100 Hz 物理 / 60 FPS。

**工程零二进制资产、零 .meta 文件：** 模型为原语拼装、纹理与音频全部程序化生成、
UI 纯代码、场景运行时构建——仓库只含文本文件，导入即可运行。

---

## 一、快速开始

1. **安装 Unity 2022.3 LTS**（推荐 2022.3.20f1，任意 2022.3.x 均可）：
   Unity Hub → Installs → 安装 Windows Build Support 的 2022.3 版本。
   无需任何额外模块（不依赖 Input System、URP、TextMeshPro）。
2. **打开工程**：Unity Hub → Open → Add project from disk → 选择本目录 `D:\RCPlaza`。
3. **首次导入**：等待 1–2 分钟（自动生成 Library 与全部 .meta）。
4. **运行**：打开 `Assets/RCPlaza/Scenes/RCPlaza_Minimal.unity` → 按 Play。
   > 双保险：即使不打开任何场景（例如编辑器里的 New Scene），按 Play 同样完整运行——
   > 入口是 `[RuntimeInitializeOnLoadMethod]` 引导，与场景内容无关。

## 二、操作

| 按键 | 功能 |
|---|---|
| `W` / `↑` | 前进（油门） |
| `S` / `↓` | 前进时刹车；低速持续按住 → 倒车（30% 功率，真实 ESC 逻辑） |

## 六、对设计文档的六处公开偏差

1. **悬架参数修正**：文档 §3.3 的 k=28000–32000 N/m 会使 2.64 kg 车身静态压缩仅
   0.21 mm（悬挂视觉冻结），与文档自身的 "TargetPosition 0.5" 矛盾。
   修正为按"静载压缩 ≈ 50% 行程"反推：SCT k≈370 N/m、c≈25 N·s/m；MT k≈530、c≈40。
   文档原值保留在 `CarSpec.cs` 注释中备查。
2. **电机扭矩曲线**：文档曲线在 0 转速处扭矩为 0（车辆无法起步，是不动点），
   故改为堵转至 70% 转速全程 0.92 峰值平台（真实无刷电调起步进角 boost 特性；
   早期版本用 0.30 堵转兜底，但在轮胎反作用力矩轮转耦合补全后，0.30 兜底会把
   SCT 0→40 拖慢到 ≈4.9 s、把 MT 卡死在路沿墙下，与 §7②/§5 两项验收同时矛盾）；
   并在 95%→100% 转速段将残余扭矩衰减到 0，使极速由"风阻 × 扭矩衰减"自然
   平衡产生（纯文档曲线没有真实极速）。峰值扭矩亦按 §7② 验收经诚实扭矩通道
   （轮上力 = T·η·g/r）反向推导：SCT 0.100 N·m（0→40≈2.8 s）。
   MT 0.35 N·m 见偏差 6，MT 0→70 的真实用时见偏差 5。
3. **侧倾验收角修正**：文档 §7③ 的"定圆侧倾 3–5°"与其自身参数互斥——
   侧倾 φ = m·a_y·d_g / K_roll，代入文档给定的 CG 高 55–65 mm（§3.2）、修正后的
   k 与 25 km/h μ 饱和定圆（舵量 0.20 时 a_y = μg ≈ 5.9 m/s²），理论侧倾仅
   ≈1.3°；要凑出 3–5° 需要 CG 高 200 mm 以上，直接违反 §3.2。故验收按物理
   可达区间 1.0–3.0° 执行，偏差记录于测试注释（`PlayModeGameplayTests.cs`）。
4. **极速验收面修正（复核修订）**：文档参数表的"最高速度 约 50 km/h（2S）/ 80+
   km/h（3S）"。按工程扭矩通道逐项求解（平台扭矩 12.4 N、风阻 0.0322·v² N、
   滚阻 0.36 N、电压 sag 逐点迭代），阻力平衡点 ≈16.3 m/s ≈ **58.5 km/h
   （2S 满电）**：略高于文档 ≈50 的原因即偏差 2 的 0.92 平台（平衡点转速占比
   ≈0.73，仍在平台内）。3S 外推 ≈70 km/h——文档的"80+"需更高 Kv/齿比、且与 2S
   数值不成比例（风阻 ∝v² 吃掉了升压红利，v ∝ P^⅓）。受场地直道限制（有效
   ≈74 m），v(x) 收敛到平衡点的 ≈99%，解析应 ≈57.5–58.5 km/h（运行实测 59.0
   km/h，完整跑满直道后在物理容差内），断言区间 [52, 62] km/h：下界防"彻底
   失速"机制退化，上界为平衡点上方物理不可达区。
   旧版 README 曾给 [59, 72]——误以"平衡转速占比 0.93 × 空载轮速"估平衡点
   （空载轮速 ≈79.5 km/h 本身是 ω 空间量，且真实平衡占比 ≈0.73），本次按
   电流/电压逐项迭代复核修正，推导记录于 `PlayModeGameplayTests.cs`。

5. **MT 0→70 km/h 计时修正**：文档 §7② 要求 Kraton 0–70 km/h 达 2–3 s。该车起步
   即被 μFz 抓地上限按死（轮上力 ≈37 N > 沥青 μFz ≈31 N，峰值饱和兜底），且
   70 km/h 处风阻已吃 ≈19.8 N：t = ∫dv/(6.10−0.0108v²) ≈ **4.5 s**。要压进 3 s
   需平均加速度 6.5 m/s²、终点合力 ≈52 N ≈ 1.7×μFz——在任何铺装路面上物理不可达
   （等效 μ≈1.1）。故验收按物理可达区间 [4.0, 5.5] s 执行，推导记录于
   `PlayModeGameplayTests.cs`。

6. **MT 峰值扭矩 3.5×**：文档 §2.2 指引 MT 峰值扭矩为 SCT 的 2.5–3 倍，工程取值
   0.35 N·m = 3.5×。该值反向推导自 §7②（0→70 的最短物理用时，见偏差 5）与
   §5 路沿爬升（平台扭矩下 0.5 油门可骑上 4.5 cm 路沿；扭矩过低时 MT 会被路沿墙
   卡死）。偏差记录于 `CarSpec.cs` 注释。

另有若干**稳定性工程项**（文档未列，为起步烧胎失稳所必需，注释在代码中）：
**牵引控制**（λ>0.30 时限扭、λ≥1.2 近断油，全速段常开——等价真实 ESC 防滑；
巡航 λ 天然 <0.1 故不损极速）、**轮转闭合**（轮胎纵向力以反作用力矩 −Fx·r 耦合
轮转；轮惯量 ≈1e-4 使该模式响应远快于物理步，按准静态平衡把轮速钉在"轮胎力 =
轮上扭矩"的平衡点——缺失闭合时 λ 自由跑飞：收油滑行被轮胎力顶着匀速漂移、
起步后轮速反超空载使电机扭矩归零）、**峰值饱和 + 单调上升支逆解**（平衡逆解只在
Magic 峰值前的单调段 [0, λ_p≈0.19] 上二分，扭矩需求触及 μFz 时饱和在 λ_p 即输出
抓地力上限，等价理想牵引控制——否则 λ 落进峰值后的死亡区与 TC 形成 100 Hz
极限环，实测净推力只剩 40–60%：0→40 拖到 4.3–4.5 s、极速卡在 47 km/h、滑行
40 s 未停稳）、**滚阻反力矩通道**（滚阻 −Crr·Fz·tanh(v/0.3) 并入轮上扭矩平衡，
收油滑行时平衡点自然落在 λ* = −Crr/μ 的小负滑移、轮胎稳定产出 −Crr·Fz 的
减速力——滚阻由轮胎力链条自洽实现；纯车身力通道的 tanh 尾巴会把滑距拖破
§7① 上界）、**偏航阻尼**（0.8 N·m·s/rad——等价轮胎自回正力矩与轮距几何的
共同效果，否则 Pacejka 峰值滑移率之外的负斜率区会让全油门起步原地打转）。

车型命名采用风格化描述（"短卡 SCT 型 / 大脚 MT 型"），参数注释标注了参考原型，
不复制品牌标识与精确外观（文档 §8）。

## 七、性能账目

- `Time.fixedDeltaTime = 0.01`（100 Hz 物理）、`Application.targetFrameRate = 60`；
- Rigidbody：CCD + Interpolate、`maxAngularVelocity=20`、`solverIterations=8`；
- 场景 90 个静态物体 → 两次 `StaticBatchingUtility.Combine` 合批，共享 ≈15 份材质；
- 每辆车仅 4 条悬挂射线（`Physics.DefaultRaycastLayers` 排除汽车自身的
  Ignore Raycast 层）、1 个刚体、1 个碰撞体；F2 面板左上角实时 FPS 可核对。

## 九、常见问题

- **首次打开卡的久 / 太多 .meta 变更**：正常——这是 Unity 为全部脚本/场景生成的元数据。
- **Play 后汽车不动**：检查 Console；本工程所有输入均为 `Input.GetKey`，
  与 InputManager 轴配置 / Input System 包无关。
- **有任何编译报错**：把 Console 中红字报错完整发回即可快速修复（工程无二进制
  资产，任何文件都可直接改）。
- **想调手感**：入口是 `Scripts/Core/CarSpec.cs`（车参数）与 `SurfaceData.cs`
  （路面 μ/滚阻）、`PlazaConfig.cs`（电池倍速/场景尺寸）。
